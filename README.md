# 🛒 Amazon E-Commerce Website

A full-stack e-commerce website developed using HTML, CSS, JavaScript, PHP, and MySQL.

## 📌 Project Overview

This project is an Amazon-inspired e-commerce website that provides users with an online shopping experience.

## 🚀 Features

- User Registration & Login
- Product Search
- Product Categories
- Product Browsing
- Shopping Cart
- Checkout
- Payment System
- Address Details
- Order Management
- MySQL Database Integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Git & GitHub

## ⚙️ How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` folder.
4. Open phpMyAdmin.
5. Create the database.
6. Import `database.sql`.
7. Configure `config.php`.
8. Open the project in your browser:

`http://localhost/Amazon/`

## 🎯 Purpose

This project demonstrates full-stack web development using PHP and MySQL with an e-commerce shopping system.
